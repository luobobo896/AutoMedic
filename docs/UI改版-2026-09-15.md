# AutoMedic Web 改版记录（对齐参考截图）

> 日期：2026-09-15 · 范围：`web/`（Vue 3 + Element Plus + Vite）
> 设计来源：用户提供的 6 张参考截图（PulseOps 风格的自愈平台界面）作为**设计规格**，不另行发挥。
> 目标：① 视觉/配色/间距/组件向参考图看齐；② 业务流转比改版前更清晰；③ 布局分区与响应式更合理。

---

## 0. 结论

改版前是**全暗色终端风**（`--am-bg: #161618`），信息层级靠卡片堆叠，业务链路只在表格里体现；
参考截图是**深蓝侧栏 + 浅色工作区**的企业控制台，它把「看盘 → 事件 → 流程 → 统计」拆成职责单一的页面，
并在详情页用**阶段轨道 / 处置链路时间线**把流转过程可视化。

因此本次改动分三层：**token 层换主题**（23 个页面自动跟随）、**外壳与布局层重建**（侧栏分组 + 页头规范 + 表格列宽预算）、
**业务层重组**（仪表盘只做盘面、事件详情给链路、流程监控给阶段）。

配色取自参考图实测像素：侧栏 `#041528`、画布 `#f0f2f5`、卡片 `#ffffff`、主色 `#3178f7`（按 WCAG AA 压深为 `#2b6ef0`）、
表头/条纹 `#fafafa`、分隔线 `#f0f0f0`、代码块 `#0e1116`、语义色 `#ed5d54 / #f0b03e / #70c03e`（文字用压深版本保证 4.5:1）。

## 4. 未做 / 已知边界

- **没有生成 Image Gen 概念图**：用户已给出 6 张参考截图作为设计规格，按参考图做保真实现比另造一版概念更符合诉求。
- **事件详情仍是抽屉**（未新增 `/events/:id` 路由）：抽屉内已完成双栏 + 时间线，新增路由属于功能扩展，未做。
- **只保留浅色主题**：原「未来支持浅色」的双主题分支按 YAGNI 移除；若日后要暗色，改 `:root` 一组 token 即可。
- **≤1024px 表格横向滚动**：数据密集表在窄屏用容器滚动（参考图同样如此），未做列级隐藏。
- **本地 `web/.env.development` 的 WS 修复未纳入版本控制**（该文件被 `.gitignore` 的 `.env.*` 排除）：
  原值 `VITE_WS_BASE=ws://127.0.0.1:8080` 属跨源，会被服务端 WS Origin 校验拒绝（403），
  导致流程监控一直显示「离线（轮询）」；本地已改为留空（走 Vite 代理同源）。其他开发机需要同样处理。
