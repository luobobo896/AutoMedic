## 1. 问题分类与优化规则

### 1.1 信息密度失控

**规则 D1 — 文案三上限**：单条关键信息 ≤ 30 字；段落 ≤ 3 行；一张卡片只有一个主行动点（CTA）。
现状达标示例（保留）：`ProjectList.vue` 引导卡「四步接入：项目 → 仓库 → 规则 → 令牌」+ 副文案一行，即为此标准。

**规则 D2 — 分组建立层级**：按功能模块用卡片分区，模块间距 24px，卡片内区块间距 16px，相关元素 8–12px。统一用 `.am-card` + 新增 `.am-card__title` 取代 6 处重复的 `<span style="font-weight:600">`（EventList、DictList、Dashboard 等）。

**规则 D3 — 字号阶梯**（详见 §2 token 表）：
- 正文/表单/表格：14px（当前 13.5px → 14px）
- 辅助说明：13px；标注/徽标：12px（**11px 与 12.5px 等中间值全部归档**）
- 卡片标题 16px、页面标题 18px、区块大标题 22px、统计数值 26px
- 行高：正文 1.5，说明文字 1.6

**规则 D4 — Dashboard 首屏减负**：8 张统计卡 → 按「核心四卡（任务/待确认/成功/失败）+ 次要四项合并为一行摘要文本」重组；移动端统计卡 `grid-template-columns: repeat(2, 1fr)`（当前 auto-fit 单列会让用户连划 8 屏）。

**规则 D5 — 内联样式清零**：155 处 `style="..."` 逐类替换为语义类（`am-card__title`、`am-mt-2` 等工具类或组件 prop），新增 lint 约束（见 §8）。

### 1.2 组件样式不统一

**规则 C1 — 唯一事实源**：所有颜色/字号/圆角/间距/阴影只能引用 `--am-*` token 或其 EP 桥接变量；图表色从 `constants/tokens.js`（§2.4）读取，禁止手写 hex。

**规则 C2 — 同语义同实现**：卡片一律 `.am-card`（登录卡 18px 圆角 → 12px）；区块标题一律 `.am-card__title`；空态一律 `.am-empty`；危险操作一律 `AmButton type="danger"` 或 `type="danger"` link。删除 5 个文件中的死类名 `am-btn-primary/am-btn-soft`。

**规则 C3 — 四态齐全**：每个可交互组件必须定义 default / hover / press(`:active`) / disabled(`.is-disabled`) + `:focus-visible`，变量命名与对照表见 §3。

### 1.3 主题闪烁

现状确认：`index.html` 静态内联背景 `#161618` + `#am-boot` 占位 + `main.js` 先 `await bootstrapSession()` 再 mount，机制正确（生产构建 CSS 走 `<link>` 在首帧前加载，dev 模式注入顺序也在 mount 前）。
**要做的不是修 bug，而是固化为标准模式**（§5）：内联主题初始化脚本 + `color-scheme` + `theme-color`，让未来引入浅色主题或第三方注入 CSS 时不会回归闪黑/闪白。

### 1.4 多端适配

**规则 R1 — 断点单源**：375 / 768 / 1024 三档（见 §6.1），CSS 与 JS 共用一份常量。
**规则 R2 — 导航形态**：<768px 抽屉式侧栏（现状保留，16 个菜单项不适合底部导航）；768–1023px 收窄侧栏；≥1024px 完整侧栏。
**规则 R3 — 触区**：移动端所有可点元素 ≥44×44px、相邻触区间距 ≥8px。
**规则 R4 — 栅格**：`el-col` 必须带响应式属性（修复 Dashboard/Statistics 的 P0 bug）。

### 1.5 按钮规范

**规则 B1–B5**：居中、内边距 ≥12px、统一高度（small 32 / medium 40 / large 44，移动端全 44）、最小宽度 88px、超长省略号 + `title`。统一封装 `AmButton`（§7）。

## 3. 组件四态规范（状态对照表 + 变量命名）

### 3.1 状态对照表（暗色主题）

| 类型 | 默认 | 悬停 hover | 按下 press | 禁用 disabled | 键盘焦点 focus-visible |
|------|------|-----------|-----------|--------------|----------------------|
| primary 按钮 | `bg --am-primary` / 文字 `--am-on-accent` | `--am-primary-hover` | `--am-primary-press` | `opacity .45` + `cursor:not-allowed` | `outline 2px --am-primary, offset 2px` |
| secondary 按钮 | `bg --am-bg-inset` / 边 `--am-border` | 边 `--am-border-strong` | `bg --am-bg` | 同上 | 同上 |
| ghost/link 按钮 | 文字 `--am-primary` / 透明底 | 文字 `--am-primary-hover` + `--am-primary-soft` 底 | 文字 `--am-primary-press` | 同上 | 同上 |
| danger 按钮 | `bg --am-danger` / 文字 `--am-on-accent` | `--am-danger-hover` | `--am-danger-press` | 同上 | `outline 2px --am-danger` |
| 输入框 | `bg --am-bg-inset` / 内描边 `--am-border` | 内描边 `--am-border-strong` | —（无按下态） | `opacity .45` + 输入锁定 | 内描边 `1.5px --am-primary` + 外扩 `3px --am-primary-soft`（现状保留） |
| 下拉项 | 透明 | `bg --am-bg-inset` | 同 hover | `opacity .45` | 同上 |
| 卡片（可点击） | 边 `--am-border` | 边 `--am-border-strong`（**不做 scale，避免布局抖动**） | 边 `--am-primary` | 不适用 | 同按钮 |

统一规则：禁用态一律 `opacity: .45`，悬停无变化，`cursor: not-allowed`；过渡统一 `var(--am-duration) var(--am-easing)`，只过渡 `background-color/border-color/color/box-shadow/opacity`。

### 3.2 CSS 骨架（并入 `styles/index.css`）

```css

.el-button--small { min-height: var(--am-control-h-sm); }
.el-button--large { min-height: var(--am-control-h-lg); }
.el-button.is-disabled { opacity: .45; cursor: not-allowed; }

  background: var(--am-danger); border-color: transparent; color: var(--am-on-accent); font-weight: 600;
}
.el-button--danger:hover, .el-button--danger:focus { background: var(--am-danger-hover); }
.el-button--danger:active { background: var(--am-danger-press); }

/* ghost：现有 is-link 柔化，补 hover 底色 */
.el-button.is-link { border-radius: var(--am-radius-sm); min-height: var(--am-control-h-sm); }
.el-button.is-link:hover { background: var(--am-primary-soft); }

/* 可点击卡片（am-proj 等）：只动边框不动布局 */
.am-proj { transition: border-color var(--am-duration) var(--am-easing); }
.am-proj:hover { border-color: var(--am-border-strong); }
```

## 5. 主题初始化与防闪烁（固化方案）

现状机制（`index.html` + `main.js:28`）已消除闪黑/闪白，本节将其固化为**可支持未来浅色主题**的标准模式，防回归：

### 5.1 index.html 首屏内联主题初始化（替换现有 `<style>`）

```html
<!DOCTYPE html>
<html lang="zh-CN" class="dark" data-theme="dark">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover" />
  <meta name="theme-color" content="#161618" />
  <title>AutoMedic · 自动修复平台</title>
  <style>
    /* 首帧兜底：与 --am-bg 同色，先于任何 CSS 加载生效 */
    html, body, #app { margin: 0; height: 100%; background: #161618; color: #9a9aa3; color-scheme: dark; }
    #am-boot {
      position: fixed; inset: 0; display: flex; flex-direction: column; gap: 8px;
      align-items: center; justify-content: center;
      font: 14px/1.6 -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", sans-serif;
      background: #161618; color: #9a9aa3; transition: opacity .18s ease;
    }
    #am-boot.is-done { opacity: 0; pointer-events: none; }
  </style>
  <script>
    // 主题初始化：在首帧渲染前同步执行，读 storage 决定 dark/light，
    // 未来加浅色主题时只需扩展 THEME_BG 映射，不会出现闪色。
    (function () {
      var saved = null
      try { saved = localStorage.getItem('am.theme') } catch (e) {}
      var theme = saved === 'light' ? 'light' : 'dark'   // 当前仅 dark
      var root = document.documentElement
      root.classList.toggle('dark', theme === 'dark')
      root.setAttribute('data-theme', theme)
      // boot 文案按是否首访区分，避免登录页显示「恢复会话」
      var boot = document.getElementById('am-boot-text')
      if (boot && location.hash.indexOf('#/login') === 0) boot.textContent = 'AutoMedic 加载中…'
    })()
  </script>
</head>
<body>
  <div id="app"><div id="am-boot"><span id="am-boot-text">AutoMedic 正在恢复会话…</span></div></div>
  <script type="module" src="/src/main.js"></script>
</body>
</html>
```

### 5.2 卸载 boot 占位（main.js mount 后）

```js
bootstrapSession().finally(() => {
  app.mount('#app')
  const boot = document.getElementById('am-boot')
  if (boot) { boot.classList.add('is-done'); setTimeout(() => boot.remove(), 200) }
})
```

### 5.3 时序说明（为什么这样不闪）

1. HTML 解析 → 内联 `<style>` 立即生效，背景 `#161618` 首帧着色（**无白**）；
2. 内联 `<script>` 同步设置 `class="dark"` / `data-theme`，先于 EP CSS 加载（**无暗↔亮切换**）；
3. 生产构建所有 CSS 经 `<link>` 在渲染前加载；dev 模式 CSS 注入发生在 `app.mount()` 之前；
4. `main.js` 先 `await bootstrapSession()` 再 mount，避免「未登录→/login→续期→跳回」二次导航闪屏（现有注释所述，保留）；
5. boot 淡出移除，避免占位层与应用层重叠。

## 6. 响应式策略

### 6.1 断点单源（手机 ≥375 / 平板 ≥768 / 桌面 ≥1024）

新增 `web/src/constants/breakpoints.js`：

```js
export const BP = { mobile: 375, tablet: 768, desktop: 1024 }
// matchMedia 用 (max-width: 767.98px) 表达「< tablet」，与 CSS 断点边界一致
export const MQ = {
  ltTablet: `(max-width: ${BP.tablet - 0.02}px)`,
  ltDesktop: `(max-width: ${BP.desktop - 0.02}px)`,
}
```

新增 `web/src/composables/useBreakpoint.js`（替代 `AppLayout.vue:94-96,123-130` 的 resize 轮询）：

```js
import { ref, onMounted, onUnmounted } from 'vue'
import { MQ } from '@/constants/breakpoints'

export function useBreakpoint() {
  const isMobile = ref(false)
  const isTablet = ref(false)
  let m1, m2
  const update = () => { isMobile.value = m1.matches; isTablet.value = m2.matches }
  onMounted(() => {
    m1 = window.matchMedia(MQ.ltTablet)
    m2 = window.matchMedia(MQ.ltDesktop)
    update()
    m1.addEventListener('change', update)
    m2.addEventListener('change', update)
  })
  onUnmounted(() => {
    m1.removeEventListener('change', update)
    m2.removeEventListener('change', update)
  })
  return { isMobile, isTablet }  // isMobile: <768；isTablet: 768–1023
}
```

CSS 断点继续用 `@media (max-width: 767.98px)` / `(max-width: 1023.98px)`，与 JS 常量同源定义（`breakpoints.js` 顶部注释注明对应关系）。
