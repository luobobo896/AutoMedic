# 2026-09-08

## 平台级改造：登录方式 + 多租户 + RBAC + PostgreSQL

### 1. 登录方式：令牌 → 账号密码
- 后端新增 `internal/auth`：bcrypt 密码、JWT（access + refresh 双令牌，refresh 存库可吊销）。
- 接口：`POST /api/v1/auth/login|refresh|logout`、`GET /auth/profile`、`PUT /auth/password`。
- 鉴权从 `X-Admin-Token` 改为 `Authorization: Bearer <jwt>`；WS 走 `?token=` 查询参数。
- 前端 `web/src/api/index.js`：401 自动续期一次，失败清会话跳登录；`AppLayout` 顶栏改为用户菜单（改密码/退出）。

### 2. 多租户 + RBAC
- 数据隔离粒度（用户确认）：**业务数据按租户隔离，模型配置（Provider/LLMModel）全局共享**。
- 新增实体：Tenant / User / Role / RolePermission / UserRole / AuthToken；业务表（Project/Repo/Credential/Rule/Event/Task/IngestToken/ReviewJob/CredentialUsage）加 `tenant_id`。
- 权限码 `资源:动作` 目录在 `model/rbac.go`；内置角色：super_admin(平台)、tenant_admin/developer/viewer(每租户)。
- 超管可跨租户（`X-Tenant-ID` 头切换），非超管强制本租户过滤（api 层 `h.tdb(c)` 统一加 `tenant_id`）。
- 前端新增 用户管理/角色权限/租户管理 三个页面；路由守卫按 `meta.perm` 过滤菜单与访问。

### 3. PostgreSQL
- `store/db.go` 新增 postgres 驱动（gorm.io/driver/postgres）；`Dialect` 全局变量。
- SQL 方言适配 `api/dialect.go`：`sum(case when…)` / `to_char` / `::text` / GROUP BY 列补全。
- 目标库：`new.hsddns.com:5432` 账号 admin，库 automedic（TEMPLATE template0 创建，避开 collation 版本不匹配）。
- 配置：`configs/config.yaml` 已切 postgres；`auth.jwt_secret` + `auth.bootstrap_admin`（admin/admin123，默认租户 default）。
- 种子：`store/seed_rbac.go` 幂等创建租户/角色/权限/超管；`SeedDefault` 继续种厂家与模型。
