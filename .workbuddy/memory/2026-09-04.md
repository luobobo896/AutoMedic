### 踩坑记录（重要）
1. **npm install 被 CodeBuddy broker 沙箱拒绝（CODEBUDDY_BROKER_DENY）**：在 ASCII 临时目录 `/tmp/am-build` 安装，再 `ln -s` 到 `web/node_modules`。装完需循环重试补齐（vite/@vitejs/plugin-vue/@vue/shared 曾出现空目录，用 `find -empty -delete` 后重装）。
2. **构建必须用 `node node_modules/vite/bin/vite.js build`**（vite bin 不在 PATH）。
3. **Vue 模板里写 `{{ '{{.Bin}}' }}` 会报 Unterminated string constant**，改用 `<code v-pre>{{.Bin}}</code>`。
4. **git 子进程相对路径错位**（`git clean` chdir no such file）：工作区与 Root 统一 `filepath.Abs`。
5. **dsh 把平台写入的 AUTOMEDIC.md/AGENTS.md 算作代码变更**：`WriteInstruction` 只新建不存在的文件并记录 `.automedic/managed-files.json`，`CleanupArtifacts` 按清单精准删除；`no_code_change` 优先从 result.json 读。
6. Go 并行 Edit 同一文件会互相覆盖，曾导致多处 undefined；大改建议串行。
7. `model.JSON` 需自定义 `MarshalJSON`，否则序列化成 base64（如 `"e30="`）。
8. 写 YAML 配置别在首行漏 `#`，否则 yaml.Unmarshal 报 line 1 cannot unmarshal !!str。
